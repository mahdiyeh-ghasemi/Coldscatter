# Third-party software notices

Coldscatter's own source code is distributed under the MIT License in
the repository's `LICENSE` file. That license does not replace the
licenses of third-party dependencies.

The declared runtime dependencies are NumPy and SciPy. Matplotlib is an
optional dependency for plots and examples; pytest is an optional
dependency for running the test suite.

- NumPy: https://numpy.org/
- SciPy: https://scipy.org/
- Matplotlib: https://matplotlib.org/
- pytest: https://pytest.org/

Consult the license and notice files supplied with the exact versions
and binary distributions installed in a particular environment.
Scientific Python binary distributions can bundle additional libraries
whose notices and license terms vary by build and platform.

This file is an attribution guide, not a complete manifest of every
transitive dependency or bundled binary component. When redistributing
an environment, installer, container, or binary bundle, generate and
include the applicable notices for that exact artifact. Do not copy
license text from an unrelated package into Coldscatter's own `LICENSE`.
